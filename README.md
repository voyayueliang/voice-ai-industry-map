# Frontier Field Atlas · 前沿 AI 行业人物研究引擎

在线访问：https://voyayueliang.github.io/voice-ai-industry-map/

这是一个面向“带着真实任务进入陌生 AI 领域的专业新手”的研究工具。它帮助内容研究者、人物采访者、生态工作者和相邻领域决策者，先建立行业结构，再发现人物、核验关系和准备进一步研究。

Voice AI 是第一份经过人工核验的公开样本。根页面以黑色 3D 关系网络连接人物、产品、技术路线和公开来源；`/research` 可以输入其他 AI 领域，先生成领域结构草案，再从 GitHub 公开项目和 Crossref 论文元数据发现第一批人物线索；`/guide` 提供 Voice AI 六层学习导读。

## 三种使用方式

- 学习：理解一个行业解决什么问题、由哪些层级共同运转；
- 研究：从公开论文和开源贡献发现候选人物、项目与证据关系；
- 访谈：识别人物当前缺失的身份、贡献、变化和独立证据，建立研究队列。

自动检索结果只是线索，不是行业榜单或已核验人物档案。人物进入公开图谱前，仍需核验当前身份、个人贡献、持续价值、独立证据与关系性质。

## Voice AI 已核验样本解决什么

- 沿“声音入口—实时传输—音频模型—Agent 与记忆—产品应用—生态分发”理解一次 Voice AI 对话经过什么；
- 查看人物主要解决哪一层问题，以及对其他层产生什么影响；
- 在人物邻域中区分共同任职、同一路线、替代路线、结构性上下游和技术影响；
- 通过“人物—产品／项目—新闻报道”查看公开报道的时间、角度、证据等级和使用边界；
- 从人物节点进入已核验的个人主页、公司、项目和开源入口。

它不是公司排名、影响力榜单或严格供应链图。人物位置和比较关系是基于公开资料形成的编辑判断；关系数量不等于影响力。

## 当前公开数据

- 29 条已核验人物与团队记录；
- 6 个行业层级；
- 27 位人物进入 35 条有说明的关系网络；
- 25 位人物接入 71 个经核验的个人、公司或项目公开入口；

- 根页面默认打开行业全图，选择人物后进入人物邻域。

## 数据边界

- 只纳入可以通过公开职业资料、官方项目、论文、开源仓库或媒体报道核验的人物；
- 候选人可以来自私人推荐、公开研究或行业活动，但是否公开呈现只取决于公开证据；推荐人身份和私人关系路径不随人物一起披露；
- 未核验身份、私人关系路径、内部研究文档和合作讨论不进入公开仓库；
- 同一路线、替代路线和上下游关系可能是结构性比较，不代表商业合作、私人关系或直接师承；
- 公司稿、活动回顾和社区评论会标明来源等级，不作为独立媒体评价使用。
- `/research` 的 GitHub 贡献和 Crossref 论文署名只证明公开平台记录，不自动证明当前职位、项目决策权或行业影响；
- 研究队列只保存在当前浏览器，导出的 JSON 会保留自动发现与人工核验之间的证据边界；
- 公开版不存放 API 密钥，不抓取受限 LinkedIn 资料，也不会把语义相似或同场出现自动画成合作关系。

## 交互参考与许可边界

星域关系图的探索方式参考了开源项目 [Silverfish／衣鱼人物关系图谱](https://github.com/xumengke2025-sys/silverfish)。Silverfish 使用 AGPL-3.0 许可；本项目没有复制其代码，而是依据公开行业资料独立实现视觉、数据结构与交互。
